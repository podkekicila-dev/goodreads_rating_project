# Проект: Прогнозирование рейтинга книг на Goodreads

## Описание проекта
Цель — построить модель регрессии для предсказания среднего рейтинга книги.

## Тип задачи
Регрессия (предсказание числа от 1 до 5)

## Источник данных
Goodreads Books Dataset (Kaggle)
Размер: ~11,000 книг

## Признаки
- num_pages (количество страниц)
- ratings_count (количество оценок)
- text_reviews_count (количество отзывов)
- publication_year (год публикации)

## Целевая переменная
average_rating (средний рейтинг)

## Запуск проекта
1. Открыть терминал в VS Code (Ctrl + `)
2. Активировать окружение: .\venv\Scripts\Activate.ps1
3. Установить пакеты: pip install -r requirements.txt
4. Загрузить данные: cd src && python download_data.py
